## 摘要

本发明公开了一种单杯高速榨汁机，所述榨汁机包括搅拌装置、底座、清洗装置和操作屏，所述清洗装置安装在底座上，所述搅拌装置位于清洗装置上；所述底座上还设置有杯子，所述底座靠近清洗装置的一端设置有电动推杆，所述底座随着电动推杆作伸缩运动；所述底座上端面分别设置有制作位触板和清洗位触板，所述电动推杆前端分别设置有清洗传感器和制作传感器，所述操作屏内设置有控制板，所述清洗传感器、制作传感器、电动推杆、搅拌装置分别与控制板电连接，所述控制板接收操作屏的指令控制整个操作进程。本发明不仅提高了制作效率，节省了人力，同时极大程度的保证了饮品的口感，避免出现食品浪费等现象，有效实用。

## 说明书

### 技术领域

本发明涉及榨汁机器领域，具体是一种单杯高速榨汁机。

### 背景技术

现有榨汁机制作果昔奶昔等产品，都是现切水果，放进机器搅拌，由于会预制一部分水果，会有食品安全隐患，而且一台机器每次只能做一种口味，需要做完后清洗搅拌桶，再做另一种口味，效率很低，人工成本很高，造成的食品浪费率较高。

因此我们希望可以发明一种榨汁机，需要制作哪种口味的饮料时，就可以拿哪种冰杯现场搅拌，顾客直接拿杯子饮用，搅拌后可以自动清洗刀头及接触食品的机器附件，由于直接在饮用的杯内搅拌，可以减少浪费和食品安全的问题。

### 发明内容

**核心技术方案：**

一种单杯高速榨汁机，所述榨汁机包括搅拌装置、底座、清洗装置和操作屏，所述清洗装置安装在底座上，所述搅拌装置位于清洗装置上；所述底座上还设置有杯子，所述底座靠近清洗装置的一端设置有电动推杆，所述底座随着电动推杆作伸缩运动；所述底座上端面分别设置有制作位触板和清洗位触板，所述电动推杆前端分别设置有清洗传感器和制作传感器，所述操作屏内设置有控制板。

**搅拌装置**包括底板、电机、顶板、滚珠丝杠和高速电机座。电机带动主动轮转动，通过传动带带动从动轮转动，滚珠丝杠随之转动，套在滚珠丝杠上的高速电机座进行升降操作。高速电机控制搅拌轴和刀头旋转，在杯子中直接搅拌。

**清洗装置**包括清洗筒、清洗喷头和电磁阀。制作完成后，电动推杆将清洗装置移动至搅拌装置下方，电磁阀控制清洗喷头喷出高压水雾冲洗刀头、搅拌轴及硅胶密封盖。

**硅胶密封盖+弹簧密封机制**：弹簧在高速电机座下降时压住硅胶密封盖并压住杯子，保证杯内处于密封环境，防止搅拌液溅出，保证汁液口感。

**编码盘+升降传感器精确定位**：编码盘上有若干个孔，升降传感器发出光线，通过从动轮旋转使编码盘不停遮光透光，程序通过识别孔数来确定高速电机座的精确高度。

**安全防护系统**：零位传感器、第一防护传感器、第二防护传感器和护板传感器组成多重安全保护。制作/清洗过程中传感器被触发会立即断开整机供电。另配急停按钮。

**自动制作+自动清洗工作流程：**
1. 操作屏按下制作图标 → 机器检测各运动部件位置 → 电机驱动滚珠丝杠使高速电机座上升 → 触发零位传感器后电机停止
2. 电动推杆收缩 → 底座带动杯子向左移动 → 制作位触板触发制作传感器 → 进入预设制作程序
3. 电机转动驱动滚珠丝杠 → 高速电机座下降 → 硅胶密封盖压住杯子 → 电机停止、高速电机启动 → 刀头旋转搅拌 → 制作完成
4. 高速电机座提升回零位 → 电动推杆伸出 → 清洗筒移动到搅拌装置下方 → 清洗位触板触发清洗传感器
5. 高速电机座下降 → 硅胶密封盖压住清洗筒 → 高速电机带动刀头旋转 → 电磁阀打开 → 清洗喷头喷高压水雾 → 废水经排水盒排出

### 有益效果

1. **单杯制作**：直接在饮用杯内搅拌，需要哪种口味就拿哪种冰杯现场搅拌，一机多口味
2. **自动清洗**：每次制作后自动清洗刀头，无需人工清洗搅拌桶，效率高、人力省
3. **食品安全**：避免预制水果的安全隐患，单杯搅拌无交叉污染
4. **减少浪费**：直接在饮用杯内搅拌，减少食品浪费
5. **密封防溅**：硅胶密封盖+弹簧保证搅拌过程密封，汁液不溅出
6. **精确定位**：编码盘+升降传感器精确控制高速电机座位置
7. **安全防护**：多重传感器+急停按钮保障操作安全
