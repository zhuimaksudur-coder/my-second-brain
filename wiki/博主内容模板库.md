# 博主内容模板库

“20 个顶级博主的大脑提示词”是一组从财经、商业、人文、产业与军事科技类内容中归纳的创作参考模板，用于[[数字人内容工厂]]的选题、结构和表达风格研究。

## 共同结构

多数模板采用以下框架：IP 定位 → 目标受众与心理诉求 → 内容方向和选题策略 → 热点结合 → 标准化创作流程 → 标题/开头/论证/结尾 → 语言风格 → 质量检查。

## 使用方式

- 抽取“生活化类比、产业深描、冲突开场、案例论证、数据解释”等可复用技法，不机械模仿具体博主措辞。
- 为[[吃法]]作者 IP 和“吃法君”分别建立自有语气规范，再按平台、受众和目标选择结构。
- 生成内容必须回到原始材料核验，尤其是商业数据、人物言论、健康和技术结论。
- 不应冒充所分析的博主，也不应复制其独特表达或受版权保护的原文；模板只用于学习抽象方法。
