# 《吃法》短视频养号垂类关键词体系

> 作者：王根祖 | 整理日期：2026-08-26
> 适用阶段：账号冷启动/养号期（前30-60条内容）

## 一、养号策略总纲

### 1.1 核心矛盾

《吃法》全书15章，内容横跨文明史、食品科技、零售革命、商业终局、中国出海、AI品牌六大板块，23 anticipate238条脚本已备。但**养号阶段最忌"什么都发"**——算法无法给账号贴标签，就不会把内容推荐给任何确定性人群。

### 1.2 垂类定位决策

| 方案 | 垂类 | 优点 | 缺点 | 判定 |
|------|------|------|------|------|
| A | 美食/吃播 | 流量池最大 | 与《吃法》调性不符，吸引来的不是目标用户 | ❌ |
| B | 纯商业思维 | 流量大，身份匹配 | 太宽泛，没有差异化锚点，淹没在大量同质账号中 | ⚠️ |
| C | 食品科技 | 专业壁垒高 | 流量池偏小，冷启动困难 | ⚠️ |
| **D** | **商业认知×食品产业** | **交叉垂类，既有流量池又有差异化锚点，与《吃法》"从文明史看食物商业"的定位完全吻合** | **需要控制商业内容与知识内容的配比** | **✅ 选定** |

### 1.3 养号三原则

1. **先贴标签，再扩散**：前30条内容严格围绕核心垂类，让算法快速给账号打上"食品产业+商业认知"的双标签
2. **知识为主，商业为辅**：养号期80%内容输出知识/观点/故事，20%软植入产品/书籍，不硬广
3. **蹭大词流量，立自造词**：用大流量词蹭入口流量，同时持续占位自造概念词，建立品类心智

## 三、话题标签组合模板

### 3.1 标准组合公式

> **每条视频挂3-4个话题标签**，按以下公式组合：

```
A簇（商业认知）×1 + B簇（食品产业）×1 + C簇（文明视角）×1 + D簇（流量入口）×0-1
```

| 内容类型 | 标签组合 | 示例 |

## 四、各平台差异说明

### 4.1 抖音（主阵地）

| 维度 | 策略 |
|------|------|
| 养号周期 | 30-60条内容（约15-30天，日更或隔日更） |
| 垂类选择 | 商业认知×食品产业（选定方案D） |
| 标签数量 | 每条3-4个，不超过5个 |
| 视频时长 | 养号期30-45秒为主（完播率优先），可偶尔.Depth80秒+ |
| 互动策略 | 前10条不引导关注/购买，纯输出价值，评论区积极回复 |
| 直播 | 养号期不开直播（开了也没人，反而拉低数据） |

### 4.2 视频号（微信生态）

| 维度 | 策略 |
|------|------|
| 差异 | 视频号社交推荐权重高，王老师朋友圈人脉是天然冷启动池 |
| 垂类 | 可比抖音更偏"知识/商业"向，受众年龄偏大、偏商务 |
| 标签 | 视频号话题标签权重不如抖音，但#话题仍有搜索价值 |
| 策略 | 前5条发到朋友圈求点赞（社交冷启动），之后靠内容自然推 |

### 4.3 小红书

| 维度 | 策略 |
|------|------|
| 差异 | 小红书偏"生活方式"，《吃法》的商业内容需调整为"健康饮食/食品科普"视角 |
| 垂类调整 | 食品产业 > 商业认知，偏向B3`#饮食健康` + D3`#健康饮食` |
| 标签 | 每条5-8个（小红书标签权重高，多挂无妨） |
| 文案 | 图文笔记+短视频双发，标题用"你知道吗/原来如此"式好奇钩子 |

### 4.4 B站

| 维度 | 策略 |
|------|------|
| 差异 | B站偏深度内容，适合120篇完整版（60-90秒正文） |
| 垂类 | 知识区 > 商业区，标签偏C簇"文明视角" |
| 策略 | 可做"共读《吃法》"系列合集，每周1-2条长内容 |

## 六、关键说明

### 6.1 自造词策略

`#吃法进化` `#文明与食物` `#火与冰` `#工具进化` 这四个自造词流量池极小，但**战略价值极高**——它们是《吃法》的品类心智占位。养号期持续挂载，让算法逐步建立"这些词→你的账号"的关联。当未来有人搜索这些词时，你的内容是唯一结果。

### 6.2 与GEO关键词的关系

本体系的垂类话题词**不等于**GEO关键词。区别：
- GEO词：面向AI搜索引擎（Perplexity/ChatGPT/文心一言），追求"被AI引用"
- 养号垂类词：面向短视频算法推荐（抖音/视频号），追求"被算法推给人"

两套词库有交集（如"智能果昔机""鲜饮""零售革命"），但使用场景和优化逻辑不同。

### 6.3 禁忌词的解禁时机

| 禁忌词类型 | 解禁时机 | 解禁方式 |
|------------|----------|----------|
| 产品名（果音/TEAF5） | 养号期结束后（粉丝500+） | 软植入：先讲"一台机器"，再说品牌名 |
| 招商词（代理/加盟） | 账号有稳定流量后（粉丝2000+） | 评论区/主页引导，不挂话题标签 |
| 卖书词 | 全程不主动挂话题 | 个人简介写"《吃法》作者"，自然转化 |
