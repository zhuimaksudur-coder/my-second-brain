# 智能果昔机租赁模式代理合同

> **背景**：知识库中现有《【招商部】代理合同》《辽宁独家代理合同》均为**买断采购模式**，与8月更新的租赁代理政策不匹配。本合同为配套租赁政策起草的**合同模板**。
> **状态**：模板草案，正式签署前须经法律顾问审核。

合同全文见 WorkBuddy 交付文件：
`/Users/apple/WorkBuddy/2026-09-02-11-26-45/workbuddy智能果昔机租赁模式代理合同.md`（及 .docx 版）

## 合同结构速览（17章）

| 章节 | 内容要点 |
|------|---------|
| 一、定义 | 智能终端/专利果昔杯/SaaS系统/终端网点/二级租金/租赁模式（不买断） |
| 二、代理授权 | 区县独家、跨区域违约处理、区划合并归属规则 |
| 三、代理商资质 | 成立3年+、年销1000万+、-18℃冷库、维修团队、终端资源 |
| 四、设备租赁 | 单次≥3台、租期、租金标准（表格留白待定）、押金、不得以质量问题拒付租金 |
| 五、SaaS与租金管控 | 二级租金联动停机、激活费、终端合同同等条款、数据权属 |
| 六、交付验收与所有权 | 所有权归甲方、禁止转租抵押出售、点位报备 |
| 七、维修与质保 | 15个月整机质保、换件+返厂（运费乙方）、本地维修乙方负责 |
| 八、甲方扶持 | 客户/维修培训/品牌/营销/物料/供应保障 |
| 九、耗材采购 | 仅用甲方专利杯与原料 |
| 十、合同期限 | 续约优先权 |
| 十一、知识产权与合规宣传 | 禁用"零清洗/零交叉污染/全球首创"、禁投资回报承诺 |
| 十二~十七 | 保密/违约责任/解除/不可抗力/争议解决/其他 |

## 待王总确认事项

3. 违约金比例、激活费标准、各类期限天数（合同中留白处）
