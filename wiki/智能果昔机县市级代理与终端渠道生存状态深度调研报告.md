# 使用说明与研究边界

本报告服务于源头工厂的渠道设计与试点决策。“他们”被拆分为三类：县市级食品饮料经销商/渠道商（代理层）、便利店/商超/餐厅（点位层）及消费者（需求层）。研究基于截至2026年8月可获得的公开资料与行业经营逻辑；涉及机器售价、杯料成本、分成、故障率等尚未取得贵司真实数据的内容，均标注为“情景假设”，不可直接作为收益承诺。

| 证据等级 | 含义 | 本报告用法 |
|---|---|---|
| A｜官方/协会 | 国家统计局、市场监管总局、CCFA/KPMG | 用于市场规模、业态趋势、监管边界 |
| B｜专业研究 | 贝恩/Worldpanel等公开报告 | 用于消费、价格与渠道变化判断 |

# 执行摘要：八个关键判断

市场有增长，但价格承压。2025年全国餐饮收入57,982亿元，同比增长3.2%；限额以上便利店、超市零售额分别增长5.5%、4.3%，而限额以上饮料类仅增长1.0%。渠道扩张不等于单店好过。
便利店最真实的矛盾是“门店继续开、单店效率承压”。2024年CCFA样本便利店单店日销约4,634元、坪效同比下降7.1%；终端只会接受占地小、低人工、可撤机、回本清晰的项目。
餐饮终端需要第二增长曲线，但反感复杂度。高性价比、小店型、轻量化持续强化，果昔机必须让员工操作不超过三步，并把清洗、补料、报修变成标准动作。
县市代理商缺的不是新品，而是确定性。其核心恐惧依次是：机器砸手里、终端不动销、售后拖垮、原料临期、厂家跨区、政策反复、食品安全连带责任。
消费者买的是“好喝 + 看起来新鲜 + 价格合理 + 即取即走”，不是“智能设备”。健康可以支撑尝试，但复购最终由口味稳定、温度、稠度、等待时间和价格决定。
渠道策略应从“县域独家”改为“达标后独家”。保护期与活跃机数、有效杯量、回款和服务SLA绑定，避免空白市场被低质量代理锁死。
商业模型优先赚杯料与运营效率，不把设备毛利当唯一目标。先用单机贡献毛利来定义可承受的设备成本、渠道分成与回本期，再定价。
必须先完成食品合规路径。自动设备现制现售可能涉及食品经营许可/备案、自制饮品制售、设备点位报告和属地差异；全国招商前应形成“一省一清单”。
资料来源：国家统计局《2025年12月份社会消费品零售总额》；CCFA/KPMG《2025年中国便利店发展报告》；市场监管总局《食品经营许可和备案管理办法》。

# 一、市场状态：总量温和增长，单店进入效率战

## 1.1 三组宏观信号

| 指标 | 2024年 | 2025年 | 对项目的含义 |
|---|---|---|---|
| 全国餐饮收入 | 55,718亿元，+5.3% | 57,982亿元，+3.2% | 仍增长，但增速放缓；餐企更看重确定回报 |
| 限额以上饮料类 | +2.1% | +1.0% | 包装饮料价值增长偏弱，现制需靠体验和效率突围 |
| 便利店零售额 | +4.7% | +5.5% | 业态仍有韧性，是高频即饮的优先点位 |
| 超市零售额 | +2.7% | +4.3% | 可做场景补充，但审批、进场和分账通常更复杂 |
| 乡村社零 | 66,729亿元，+4.3% | 68,230亿元，+4.1% | 下沉市场并非无消费力，但价格带更敏感 |

资料来源：国家统计局2024、2025年度社会消费品零售数据。不同统计指标口径不同，不应直接相加。

## 1.2 快消市场的新常态

“量增价减”：2025年前三季度城市快消总支出增长1.3%，销量增长3.8%，平均售价下降2.4%；2025全年城市快消支出增长0.9%，平均售价下降2.6%。
下沉贡献增强：专业研究显示三至五线城市贡献了2025年快消市场约80%的增长；这支持县域布局，但也意味着产品必须符合当地价格带。
消费者追求“质价比”：既不是盲目高端，也不只是最低价。新鲜感、便利性、稳定品质与可接受价格需要同时成立。
渠道碎片化：消费者跨多种渠道购物，终端需要独家小爆品和即时消费理由，而不是再增加一个低周转SKU。
资料来源：贝恩与Worldpanel《2025年中国购物者报告》系列一、二及《2026年中国购物者报告》系列一公开摘要。

# 二、三类参与者的生存状态与痛点

## 2.1 县市级经销商/代理商

| 生存状态 | 典型痛点 | 对果昔项目的要求 |
|---|---|---|
| 传统品牌利润被压 | 价格透明、促销频繁、厂家任务重 | 必须有可持续耗材毛利，而非一次性设备差价 |
| 现金流优先于规模 | 库存、账期、终端应收占用资金 | 首批投入小；设备可分批释放；原料短账期 |
| 终端关系仍是资产 | 有关系不等于有动销能力 | 用点位数据考核，不以签约门店数自我安慰 |
| 团队一人多能 | 业务员无法长期驻店做运营 | SOP、远程监控、自动补货与异常提醒要成熟 |
| 担心厂家失信 | 跨区窜货、直营抢客、政策变化 | 区域保护规则、客户归属、价格体系写进合同 |
| 售后能力薄弱 | 设备故障会迅速消耗关系 | 备机/备件、远程诊断、24/48小时SLA |

| 代理商真正的购买理由｜“我用现有团队就能多一条高毛利、可复购的业务线，最坏情况下损失可控，厂家能解决设备与食品问题。” |
|---|

## 2.2 便利店与社区商超

便利店行业总门店和销售仍增长，但样本企业面临客流减少、客单价下降，2024年单店单日营收约4,634元、平均坪效55.9元/平方米/天，同比下降7.1%。门店会用“每平方米产出、每分钟人工、每次客诉成本”来审视新设备。

| 门店顾虑 | 隐性问题 | 必须给出的答案 |
|---|---|---|
| 占地 | 机器挤掉什么商品？ | ≤约0.5㎡优先；提供点位机会成本比较 |
| 人工 | 谁补料、清洗、处理卡杯？ | 三步操作；日清≤10分钟；责任到班次 |
| 损耗 | 卖不完、断电、冷链异常怎么办？ | 效期预警、温控记录、小批补货、报损规则 |
| 收益 | 一天卖几杯才值得？ | 展示门店净贡献，不只展示毛利率 |
| 食品安全 | 出问题谁负责？ | 许可路径、追溯、清洗记录、责任险与召回机制 |
| 体验 | 排队、噪音、飞溅、故障 | 出杯时长、成功率、噪音/卫生验收标准 |

## 2.3 餐饮门店

增长但分化：2024年餐饮总量增长5.3%，高客单价产品遇冷，高性价比快餐小吃更强；经营主体“大进大出”。
饮品加购有吸引力：可提高客单、填补非正餐时段、扩展外卖品类，但必须避免拖慢出餐。
菜单竞争激烈：消费者会直接把果昔与奶茶、咖啡、瓶装饮料和鲜榨果汁比较，单靠“健康”无法长期溢价。
餐厅更适合“搭餐/套餐”而非孤立售卖：汉堡、轻食、早餐、健身餐、亲子餐和景区餐饮的场景匹配度高于重油正餐。
资料来源：中国饭店协会《2025中国餐饮业年度报告》公开摘要。

## 2.4 消费者：尝鲜容易，复购困难

| 消费任务 | 选择标准 | 产品动作 |
|---|---|---|
| 早餐/代餐 | 饱腹、速度、可携带 | 高纤/酸奶/谷物款；90秒内完成 |
| 下午提神 | 好喝、轻负担、社交感 | 小杯低门槛；颜色与杯体有识别度 |
| 运动后 | 蛋白/能量信息可信 | 营养标示克制合规，避免医疗化宣传 |
| 亲子/家庭 | 成分可理解、卫生可见 | 配料透明、过敏原提示、清洗可视化 |
| 即时解渴 | 价格、温度、等待时间 | 核心价格带做A/B测试，非主观拍脑袋 |

# 三、项目—市场匹配：智能果昔机能解决什么

| 项目能力 | 价值成立的前提 | 若做不到的后果 |
|---|---|---|
| 自动现制 | 出杯稳定、清洗简单、成功率高 | 从“省人”变成“添乱” |
| 冷冻/冷藏杯料 | 口味一致、追溯完整、供应稳定 | 断货与波动摧毁复购 |
| 远程联网 | 能监控销量、温度、故障、效期 | 只是联网噱头，不能降低运营成本 |
| 县域代理 | 本地拓点、补货、初级售后 | 只招商不动销，形成库存和舆情风险 |
| 源头工厂 | 成本、研发、品控、交付可控 | 若只强调低价，会卷入同质化价格战 |

| 产品定位建议｜“门店的轻量现制饮品柜台”优于“高科技售货机”；招商传播先讲单店收益与运营，再讲智能化。 |
|---|

## 3.1 优先场景排序

| 优先级 | 点位类型 | 为什么适合 | 主要门槛 |
|---|---|---|---|
| S | 校园外/写字楼/医院周边便利店 | 早餐、下午与陪护高频，即取即走 | 合规、峰值排队、寒暑假波动 |
| S | 健身房/运动中心配套店 | 需求明确、内容传播强 | 客流时段集中、蛋白诉求 |
| A | 社区精品便利店/区域连锁 | 店主决策快、可复制 | 价格敏感、老板执行差异 |
| A | 轻食/西式快餐/烘焙 | 套餐加购自然、已有操作台 | 分账与菜单位置竞争 |
| B | 大型商超 | 客流大、信任强 | 进场费、账期、审批、运营半径 |
| C | 普通中餐正餐店 | 可做儿童/餐后场景 | 需求弱、员工不愿额外操作 |

# 四、单机经济模型：先算“杯”，再谈“县域独家”

以下为示范模型，不代表贵司真实收益。基础假设：零售价18元/杯；杯料及包装6.0元；支付/促销0.8元；平均损耗0.5元；终端分成4.5元；代理履约与售后1.0元。则工厂/项目体系可分配贡献为5.2元/杯。固定成本按设备折旧、通信、巡检等合计900元/月示意。

| 日均杯量 | 月销售额 | 月总贡献（5.2元/杯） | 扣固定成本后 | 判断 |
|---|---|---|---|---|
| 5杯 | 2,700元 | 780元 | -120元 | 不达标；应迁点或撤机 |
| 10杯 | 5,400元 | 1,560元 | 660元 | 勉强；需优化口味/陈列 |
| 15杯 | 8,100元 | 2,340元 | 1,440元 | 可运营 |
| 25杯 | 13,500元 | 3,900元 | 3,000元 | 优质点位 |
| 40杯 | 21,600元 | 6,240元 | 5,340元 | 明星点位，防断货 |

资料来源：情景测算：月按30天；未计增值税、所得税、总部研发营销、坏账与大修。所有参数须以贵司真实BOM、合同与试点数据替换。
单机盈亏平衡杯量 = 月固定成本 ÷ 单杯贡献 ÷ 30。按上例为900 ÷ 5.2 ÷ 30 ≈ 5.8杯/日。若设备与安装投入为18,000元、目标18个月回收，则还需每月贡献1,000元，综合门槛约12.2杯/日。

## 4.1 敏感性：最容易误判的三个变量

| 变量 | 低位 | 基准 | 高位 | 管理动作 |
|---|---|---|---|---|
| 零售价 | 15元 | 18元 | 22元 | 至少测试两个价格带与套餐价 |
| 日均杯量 | 5杯 | 15杯 | 30杯 | 按7/14/30日分阶段淘汰点位 |
| 综合损耗率 | 8% | 3% | 1% | 小批补货、效期预警、先进先出 |

| 财务纪律｜招商材料不得只展示“毛利率”。必须同时展示门店净收入、代理净贡献、工厂杯料贡献、设备回收期，并披露杯量和损耗假设。 |
|---|

# 五、推荐代理商业模式

| 模式 | 适用阶段 | 优点 | 风险/控制 |
|---|---|---|---|
| A 设备买断 | 模型成熟后 | 回款快、资产轻 | 易诱发压货；设激活率与回购/换点规则 |
| B 押金+杯料 | 起盘优先 | 门槛低、利益绑定复购 | 工厂资产重；需风控、最低杯量和撤机权 |
| C 城市运营商 | 核心县市 | 代理负责拓点、补货、初维 | 管理要求高；KPI必须数据化 |
| D 大客户联营 | 区域连锁/餐饮集团 | 复制快、品牌背书强 | 议价强、账期长、系统对接复杂 |

建议组合：前100台以“B + C”为主。代理缴纳与信用相匹配的履约保证金，工厂保留设备所有权或设置分期归属；收入按杯或杯料差价分配。代理获得区域保护，但必须达到活跃机数、有效杯量、回款率与SLA。

## 5.1 县域独家资格，不等于永久独家

| 阶段 | 期限 | 核心门槛 | 权利 |
|---|---|---|---|
| 候选运营商 | 30天 | 完成培训；提交50个点位池 | 非独家试点10台 |
| 试运营 | 60—90天 | ≥70%机器活跃；中位数≥12杯/日；回款≥95% | 临时保护，增配至20—30台 |
| 正式独家 | 12个月滚动 | 活跃率≥80%；SLA达标；无跨区/重大食安事故 | 县域独家、线索归属、阶梯返利 |
| 整改/退出 | 30—60天 | 连续两期不达标或重大违约 | 取消保护、回收设备与客户移交 |

资料来源：建议性制度。杯量门槛需按城市、季节、机型和价格带由试点校准。

# 六、90天验证路线图

| 阶段 | 时间 | 关键动作 | 通过条件 |
|---|---|---|---|
| 0 准备 | 第0—14天 | 合规清单、3—5款SKU、SOP、数据看板、合同 | 证照路径明确；连续压力测试 |
| 1 小样板 | 第15—30天 | 1城10台；覆盖3种点位；每日复盘 | 出杯成功率≥98%；无重大食安异常 |
| 2 调优 | 第31—60天 | 价格/菜单/陈列A-B；迁移低效点位 | 点位中位数达到目标；损耗可控 |
| 3 复制 | 第61—90天 | 扩至20—30台；验证代理独立运转 | 代理可自主补货、初维；回款与SLA达标 |

## 6.1 试点必须采集的数据

机器：在线率、出杯成功率、平均出杯时长、温度异常、故障类型、平均修复时间。
销售：点位/时段/SKU/价格/支付方式的杯量、退款与复购代理指标。
供应：补货频次、缺货率、损耗率、批次与效期、冷链异常。
终端：员工操作分钟数、清洗完成率、客诉、陈列执行、门店净收益。
代理：新增有效点位、激活率、回款率、巡检完成率、首次响应/修复时长。

## 6.2 点位迁移规则

第7天：检查设备可见性、价格牌、店员推荐、缺货和故障，先修执行问题。
第14天：日均低于目标50%且无改善，调整SKU/定价/套餐/位置。
第30天：仍低于盈亏线，迁点；不要让“已签门店”绑架设备资产。
旺季与淡季分别复测；避免只用夏季数据推算全年。

# 七、招商与销售打法

## 7.1 最理想的代理画像

| 维度 | 优先 | 淘汰信号 |
|---|---|---|
| 渠道 | 已有100家以上有效终端，团队可日访店 | 只有“关系”没有拜访和订单数据 |
| 品类 | 冷冻食品、乳品、酒饮、休闲食品、咖啡原料 | 完全无食品/冷链经验 |
| 能力 | 老板亲自带试点，有车仓和初级售后 | 只想招下级、先要全县独家 |
| 资金 | 能覆盖3个月运营现金流 | 依赖终端预付款或高额赊销 |
| 理念 | 接受数据考核和淘汰点位 | 只关心设备差价与首批返利 |

## 7.2 招商话术结构

先讲终端问题：低客流、低客单、缺少鲜食/现制能力。
再讲样板事实：不同点位的真实中位杯量、损耗、故障、回本期；不只展示冠军店。
再讲代理如何赚钱：杯料差价、服务收益、阶梯激励，逐项扣除履约成本。
再讲风险怎么退：试点规模、迁点权、撤机、库存换货、区域保护条件。
最后才讲机器参数、专利、工厂实力与产能。

| 禁忌｜不承诺“躺赚”“稳赚”“几个月必回本”；不以高额首批进货换独家；不把理论最高杯量当平均值。 |

# 八、食品安全与监管合规

《食品经营许可和备案管理办法》明确：利用自动设备从事食品经营应在主体业态后标注；自制饮品制售属于餐饮服务项目；通过自动设备经营，在取得经营场所许可或备案后，可在同一省级行政区域其他场所开展已取得范围的活动，跨省还需按规定报告。地方对自动设备现制现售可能有更细要求，因此全国招商不能只用一份模板。

| 合规模块 | 最低准备 | 招商前验收 |
|---|---|---|
| 主体与许可 | 明确经营主体、许可/备案项目、设备点位报告 | 属地书面咨询或办事指南留档 |
| 原料 | 供应商资质、生产许可、批次、检验、标签与过敏原 | 每杯可追溯到批次 |
| 冷链 | 运输/储存温度、异常处置、断电预案 | 温控记录可导出 |
| 清洗消毒 | 日清/周清SOP、消毒剂、记录与验证 | 门店可执行且可稽核 |
| 设备卫生 | 食品接触材料、死角、虫害、排水/废弃物 | 第三方测试与结构评审 |
| 宣传 | 营养与健康表述有证据，不触碰疾病治疗暗示 | 营销文案合规审核 |
| 召回与保险 | 批次冻结、通知、回收、客诉、责任险 | 至少完成一次桌面演练 |

资料来源：市场监管总局《食品经营许可和备案管理办法》；国家卫健委食品安全国家标准目录；广东等地自动设备现制现售监管规定。具体以属地监管部门意见为准。

# 九、主要风险与对策

| 风险 | 早期信号 | 对策 |
|---|---|---|
| 杯量不足 | 首周靠赠饮、第二周骤降 | 以复购与中位数验收；低效点位30天迁移 |
| 季节性过强 | 夏季高、冬季断崖 | 热饮/常温能力若无验证，不做承诺；按全年回收 |
| 代理压货 | 机器多、活跃机少 | 返利与活跃杯量挂钩，不与出库量挂钩 |
| 食安事故 | 温控/清洗记录缺失 | IoT告警、停机锁定、召回、保险与责任边界 |
| 售后崩溃 | 重复故障、平均修复时间上升 | 模块化备件、换机机制、区域服务半径 |
| 价格冲突 | 线上低价、跨区供货 | 统一建议零售价、串码追踪、违约处理 |
| 现金流断裂 | 终端账期拉长、库存临期 | 预付/短账期、信用额度、滚动预测 |
| 数据失真 | 只报累计杯数、不报活跃机 | 统一口径：活跃率、中位数、P25/P75、退款损耗 |

# 十一、接下来30天的决策清单

锁定真实成本：设备BOM、安装、折旧、杯料、包装、冷链、支付、促销、损耗、售后，形成一杯一表。
完成产品压力测试：至少连续500—1,000杯，记录成功率、清洗时间、温控、噪音、易损件。
选一个代表性县级市：不要选资源最强的“特例城市”，要选可复制的普通市场。
筛选2名候选代理，各自提交50个点位池，用统一评分表选10—20个点位。
限定3—5个SKU，设置两档价格和两种陈列方案，避免变量过多。
签署试运营协议：设备权属、原料采购、数据、区域、食安、撤机、客户归属、违约。
跑满90天并经历至少一次低温/低需求阶段，再决定全国招商政策。
