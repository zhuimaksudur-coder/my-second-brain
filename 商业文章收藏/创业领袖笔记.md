# 创业领袖笔记

---

## 【肖冰 · 达晨创投】

达晨专注：TMT、医疗健康、消费服务、节能环保。

穿越周期的宝贵经验。多元退出：IPO+并购+借壳+新三板。达晨的特征：专业化、渠道化、品牌化、国际化。愿景：中国创投界的常青树。

**为什么不担忧中国经济的未来：因为传统的正在死掉，而新的正在发生。** 创造性的破坏：旧的生产力崩溃，而新的生产力诞生。

### 达晨选择企业的标准

1. **选赛道，选行业** —— 现在只选风口，新兴行业，变化快、创新快，在企业高速增长的五年结婚
2. **选人、看团队**（占判断标准50%以上，其中领袖又占50%以上）
   - 有理想、有抱负的人
   - 坚韧，遇到困难仍然能坚持下去的能力（企业家精神）
   - 诚信：说到做到，呈现真实一面
3. **市场规模** —— 10亿美金以上，最好是在百亿市场上做几十个亿
4. **成长性** —— 要有非线性增长的可能，主投高速、超高速增长的公司
5. **行业地位** —— 不会投第一、第二以外的公司，因为所有行业资源和优势都会向行业第一集中
6. **投资条款** —— 估值太高或公司治理没有标准化的不能投

### 对企业家的建议

- **一定要做一流的企业，做到行业龙头。** 做行业第一时，表面上压力大，但实际上是不累的，众多资源都会向你集中。爬坡是很累的、最辛苦的，但一旦到了顶峰，反而轻松了。
- **多想一些三五年之后的事，多为未来做布局。** 今天做的事，决定了三五年之后的收益。
- 颠覆式创新，用互联网思维。不仅方向要对，还要比拼路径。

### 企业家对资本市场的二种误区

1. 特别热衷资本运作，不关注创造价值——挺危险
2. 只知道埋头苦干，不知道利用资本放大助力——会错失时间和机会

## 【朱啸虎 · 金沙江创投】

### 竞争门槛：时间是你的朋友

1. **互联网的本质是流量，传统行业的本质是地段**
   - 如何获取用户？
   - 如何留住用户？
   - 如何提高购买频次？
   - 如何提高用户每次购买的价值？

2. **判断机会是否有价值的标准**
   - 足够大的市场容量
   - 能够容易并低成本扩张（用户是否愿意主动宣传分享）
   - 可持续性，有足够的进入壁垒

3. **巨大传统行业移动互联网化将产生非常多的机会**
   - 餐饮：25390亿
   - 医疗健康：22690亿
   - 教育培训：10750亿
   - 家政服务：9370亿
   - 本地运输：4700亿
   - 汽车后服务：4500亿

4. **移动互联网更垂直化、碎片化**

5. **高频次的双边平台尤其具有战略价值。** 在同一个领域里的最佳商业模式基本会整合相同领域里的次佳商业模式，最终形成垄断。
   - 刚需VS非刚需（出租车VS代驾）
   - 高频次VS低频次（出租车VS长途客运）
   - **从低端用户往高端用户扩张远比从高端往低端切容易（低端打高端，势如破竹！）**
   - 创业要找：**高频痛点**

6. **在中国，日常生活的移动互联网化才刚刚开始，可能需要5-10年的时间不断深入。**

> **无产阶级最有生产力！**

## 【赫畅 · 黄太吉】

- **经营粉丝：真实比正确重要。**
- 道德、情感、逻辑
- **品牌的基石：品牌不是你做了什么？而是你为什么去做！**
- 营销为品牌服务，品牌为信念服务
- **伟大的品牌总是越过大脑，直达内心！心比脑大。**
- 只有内容，无关渠道
- 营销是正收益的资本投资
- 没有行业品牌，只有社区品牌
- 一群人、一种乐趣、一种价值观、做任何事！
- **性价比 → 意价比**
- 没有人可以随随便便成功，但可以认认真真失败
- 跨界打劫将成为常态
- **要么牛B，要么死**
- 道德和情感是品牌的根基
- 任何事物在今天都具备社交属性
