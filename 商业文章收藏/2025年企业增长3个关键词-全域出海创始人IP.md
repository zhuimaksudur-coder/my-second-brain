# 2025年企业增长的3个关键词：全域、出海、创始人IP

> **来源**：微信公众号「李浩新商业思考」 | **作者**：李浩同学 | **发布日期**：2025年1月23日
> **原文链接**：https://mp.weixin.qq.com/s/y3UbFuOHAaMNmlr3Xnn87A

---

充满挑战和不确定性的2024年过去了，这一年，那些还有增长的公司创始人都做对了什么？

年前，我举办了一场主题为"创业者的2024"的年末直播，和多位嘉宾一起复盘了创业者的2024，试图寻求新一年企业增长的关键。**而通过和他们的对谈，我从中提炼出了三个关键词，分别是创始人IP、出海、全域增长**。

下文中，我让卡思咨询的同学为大家整理了直播中的精华部分，以期为大家带来一些参考。而在此之前，我先为大家介绍一下参与这个话题的四位重量级嘉宾，他们分别是：

- **程雁**，茶圈程咬金主理人，一位正能量疗愈垂直类目的茶主播。其团队深耕茶行业十余年，深度绑定各大茶产区，在杭州拥有两家线下直营茶空间，联营空间15间，自躬身入局开始做创始人IP后，其视频号主账号@茶圈程咬金的故事 3个月粉丝突破十万，单条爆款视频自然流播放近6000万，单场直播的GMV近百万。
- **王根祖**，捷翔饮品CEO。捷翔饮品是非常传统的饮品供应链，主做to b业务。自从做了创始人IP，其获客路径完全改变，一条简单的视频就获得了2亿订单，随后组建了账号团队，搭建了线上的获客矩阵。而除了国内业务以外，其国外市场也收获了极高增长。
- **张晓慧**，张拉拉兰州手撕牛肉面创始人。从国家队退役后入局餐饮行业，觅姐麻辣烫做到过2000+门店，后续杀入牛肉面赛道，2024年在消费市场极其不好的情况下，门店数量翻翻达到300+，营收超10亿，明年门店数量1000+，营收30亿+。
- **Joan**，Joan姐会客厅主理人。作为国际VC机构合伙人，Joan投出了林清轩、挪瓦咖啡等多家非常优秀的国货企业，2024年开始做自己的商业访谈账号，访谈了非常多有增长、有生命力的创始人，对于商业有着非常敏锐的洞察和思考。

---

## 关键词一：创始人IP

**浩哥：开始做创始人IP后，有没有给你们的业务带来正向的价值？整体有何感受？**

**王根祖：** 去年在上你的全域增长战略课的时候，听到你说"TO B业务更要做创始人IP"，当时我就觉得要学以致用，在课堂上我就把手机里存了很久的一条介绍产品线的视频发在了视频号上，当时就有很多同行转发。

**课程结束大概第二周后，就有一个客户在看到视频后向我们下了一个一万吨的订单，之后也有客户陆续找上来合作，可以说一条视频激发了很多潜在客户。**

我觉得创始人去发视频，做IP，不仅能生动、直观、更有说服力地展示产品的独特性和奇特性，而且只要我标签打正了，就能精准分发给感兴趣的用户，此外我还能随时知道我的视频被谁看了、哪个地区的人多、看了多长时间划走等，由此也能随时修正我的内容。后续我再为新产品发布视频时，也会有很多客户看到视频后找上门来。

**张晓慧：** 其实在疫情期间我就开始做视频号了，但因为创业太忙就没有持续坚持。自从参加完浩哥的全域增长战略课后，我就竭力去做了这件事。

整体下来给我带来了三重价值，**一是为我在业务上带来了很多大客户，二是通过视频号的故事感，让加盟商更好地理解了我们的模式，这样非常有助于在沟通时形成共识；三则是通过我的内容输出，消费者和加盟商看到了更真实的我和更真实的情感，对品牌的认可度和粘性也变高了。**

**浩哥：选什么平台是做创始人IP一定会面临的问题，你为何选了视频号？视频号这一两年来给你的体感是怎么样的？**

**程雁：** 我觉得做创始人IP在选择平台时一定要跟自己的业务模型、团队规模、财力相匹配，尤其是对于初创团队来说，不可能一开始就全面铺开。之前我在上完浩总的全域增长战略课后，对八大流量平台都展开了调研，最终选择了视频号。而之所以我认为自己没有选错平台，主要基于三点：

**首先，我们进入视频号的时机比较早，得以见证了视频号这一年来的大量更迭**，包括视频号的小店变形、商家准入门槛降低、数据后台更加科学直观、人群更加精准，这让我们在抓住好时机的前提下，也逐步获得了非常正向的反馈。

**其次，我们在最短的时间内尝试了视频号的各种内容形式，从最早的商业认知，到茶馆里的小剧情、轻剧情，再到后来传播正能量的大剧情，我们会快速试错、快速迭代，定好一个方向的时候会all in 进去，高强度输出**。而在这个过程中，一旦发现某个方向有问题，我们会快速止损，把时间节点控制在半年内。毕竟对于企业来说，现金流是最重要的。

值得一提的是，在这个过程中，我也自己下场混成了一个操盘手，减少了被割韭菜的风险。而在这个过程中，创始人应该尽量保持一种松弛的状态，因为创始人一旦很紧绷，你的团队压力也会很大，在做决策时可能也会有失偏颇。

**浩哥总结：** 我曾经在线下课时讲过，在今年这个生态里面，企业要招商加盟、要扩店、扩规模的时候，创始人IP是路径最短、链接效率最高的一个手段。

但凡能把创始人IP做起来，对公司扩大规模、吸引合作伙伴都有很大的帮助。像张拉拉的业务模型是面向众多消费者的，但是也有另外一个商业诉求，就是要吸引更多加盟商加入张拉拉。所以我当时在给它做账号定位时提出了一个建议，叫做 c打b，即做 c 端用户，做消费者能看懂的内容，同时这个内容要打动 b 端，让 b 端的加盟商看到张拉拉对消费者的态度、企业的管理模式、选址模型等、运营优势等，让一个有血有肉的张拉拉被更多 b 端的合作伙伴清晰地感知到，这对于企业的业务一定会大有帮助。

## 关键词二：出海

**浩哥：我发现现在对于很多公司来说，出海已经从原来的一种可选解法演变为一个不得不做的选择。你觉得对于大部分消费品企业而言，出海是一个可行的选择吗？现在有什么路径是大家可以选择的？**

**Joan：** 如果你现在问中国的一个企业有没有出海的打算，63%~64%是有的，22%是正在考虑，然后只有剩下大概不到14%、15%没有，**这个数据是很惊人的，说明企业已经过了给那个拐点，会迅速地像滚雪球一样出去。**

在我看来，中国的出海分为三个阶段。

**第一阶段以来料加工与贸易为主，这个阶段主要依赖外贸订单**，通过加工制造将产品出口到海外市场，企业更多地是在全球产业链中扮演了制造环节的角色，而较少涉及品牌、技术和市场的深度拓展。

**第二阶段是以联想、华为、TCL、海尔等民企为代表，通过收购业务，拓展国际市场**，如TCL收购汤姆逊的彩电业务，联想收购IBM的个人电脑业务等，这些举措不仅提升了企业的国际知名度，还帮助企业获得了先进的技术和管理经验。

**目前中国企业的出海其实是处于第三阶段，这个阶段最大的不同在于呈现出了"海陆空一起出海"的态势**，不仅有华为、比亚迪这类的大型跨国公司，还包含了大量在亚马逊等电商平台活跃的中小商家，以及以阿里巴巴、TikTok等为代表的出海"四小龙"，这些企业通过多种渠道和方式进入海外市场，形成了多元化的出海格局。在这个阶段，中国的小商家想要进入北美也有了途径，而且现在800美金之内的包裹是免税的，也是利好政策。

**而在出海第三阶段，创始人具有两大核心标志，一是具备"海生性"**，不仅具备国际化的视野和决心，人也要真正出海、能够在海外市场进行深入的本地化运营；**二是相比直接从中国外派相关人员过去，更要了解并尊重当地的文化和习惯，带着敬畏心与本地员工深度链接，这样才有强劲的发展势头。**

此外，我还观察到，今年很多出海成功的案例都是把国内的营销模式搬了出去。比如我认识的一个45岁左右的传统媒体人，就决定要把在国内做MCN的模型搬到非洲去，在当地签很多网红，这件事还挺让我震惊的。

**浩哥：我了解到张拉拉牛肉面2025年除了定下1000家的开店目标外，明年还有出海计划，关于出海，我们具体是怎么考虑的？**

**张晓慧：** 我觉得张拉拉现在的团队体系已经成熟，为进一步扩展业务提供了坚实的基础。此外，在我看来，快餐品牌要想走向世界，需要具备三个条件，**一是要标准化，二是要有大单品、大爆品，三是要有文化根基**，而兰州拉面这个品类天然具备了这三个特征，再结合当下的市场环境，出海无疑是个好机会。

至于出海的国家，我们倾向于选择东南亚国家。目前张拉拉，包括我们之前做的觅姐麻辣烫，在国内的商业逻辑都是通过翻牌改造提升店铺业绩，之前有很多在商场内业绩不好的店铺，做成我们的店翻牌改造后，一个月都能有两倍增长，成效非常显著。

我在东南亚有个朋友，就是通过翻牌改造存量市场的1000多家便利店，并结合当地情形进行全域赋能，三年的时间便取得了很大的成果，我和他提到张拉拉能不能以这种形式在印尼市场铺开时，他强烈建议我去。

所以综合来看，我觉得在东南亚市场，尤其是印尼市场这种离中国近的市场复制这种商业模式，成功率会很大，而在当地建立本土化供应链和物流体系后，将来也能为更多中国的创意品牌提供支持。

**浩哥：你现在出海业务做的怎么样？出海业务是怎么做起来的？**

**王根祖：** 出海业务现在已经是我们的重心了。在我看来，海外业务实际上比国内要好做很多，体量也要大很多。

之所以能出海，是因为我有一个很好的创新产品——智能果昔机，这款产品解决了影院等场所水果榨汁的复杂流程。2021年，日本的711委托富士电机帮它开发了类似设备，随即在日本风靡，全球范围内便利店对该设备的需求量激增，我们也在2023年升级了这款机型，而在看到我发布的视频后，很多海外的客户都主动来加我，我们也陆陆续续做了一些海外客户。

去年9月，一个星期内我接待了3、4波韩国的客户，我去韩国当地考察后，发现它当地虽然只有5000多万人口，但却有5万多家便利店，市场潜力巨大，这也让我下定决定在欧美、日韩等便利店文化发达的国家需求更高的增长。

在海外市场，我们会招一位业内有人脉、懂行业的资深人士当我们的合伙人，然后鉴于之前很多海外客户都是通过短视频找到我们，**所以我们的出海策略就是要将短视频团队本地化，在不同国家建立不同的自媒体团队，以更好地理解和适应不同市场的需求和规则，然后精准输出TO B向的内容，这种IP做短视频的打法在海外市场其实还不是特别普及，因此具有很大的潜力空间。**

再加上海外市场的人工成本很高，所以对于这种自动化、智能化设备的需求量很大，所以现在整体看下来，日本、欧美、东南亚等市场的购买力是远超国内市场的。

## 关键词三：全域增长

**李浩：2024年将要过去了，现在是岁末，你回顾这一年，觉得怀念他吗？2025年的业务目标是什么？**

**程雁：** 2025年，我们还是笃定地在视频号上谋求发展。目前的视频号小号主要是以私域为主，大号则是以公域为主，借助视频号，我们真正做到了公私域联动。线下我们主要做的是生活方式社群，社群里的会员们会在线上去给我支撑，然后线上公域吸引来的客资又会留存下来成为我线下的生意机会，其实这就和卡思在全域增长战略课上的倡导一样，就是公司的营销获客一定要往全域走。全域等于线下加线上，等于公域加私域。当能力更强了之后，我们再去多平台做精细化运营。

**李浩：你多年来都是在消品这个赛道做投资，2024年，消费品这个行业整体是承压的，对于大部分公司来说完全是挑战。从你的观察来看，2024年还能做得好的企业都有哪些特征？**

**Joan：** 我一个明显的感知是，2024年表现的企业都"用好了抖音"。其实这两年来，抖音一直存在着"出不了品牌""挣不到钱"等争议，这些观点确实反映了部分人的真实体验，但也存在着一定误解，根源就在于平台的目标和我们的目标不一定是100%对齐的：**抖音更关注的是整体生态的繁荣和用户的活跃度，而商家则更关心自己的品牌建设和盈利能力。** 抖音作为一个平台，其本质在于提供内容和流量的交汇点，品牌能否在此崛起，很大程度上取决于品牌如何利用这个平台，以及如何与消费者建立有效的连接。

我觉得想要用好抖音，要有的思维是"不要把抖音当做唯一的主战场"，而是把它当做一个广告平台、一个种草平台，当做生意全域增长的驱动引擎。

2024年做得好的企业，很多都是在抖音上获得一定流量后，又通过线下、其他平台，或私域等去承接了这波流量溢出，实现了更好的增长和盈利。任何单一的平台都无法满足所有品牌和商家的需求，多元化布局、利用多个平台和渠道进行品牌推广和销售，才是更为稳妥和有效的策略。

**李浩：你之前做投资人、后来做Joan会客厅的时候都见过很多创业者。就你的观察来看，创始人具备怎样的核心特质，才能带领企业走得更远？**

**Joan：** 我认为主要有两点，**一是擅长把握、拿捏人性**；其次，我们目前所处的环境不断变化，线上线下格局总在变动，主战场永远在迁移。在这样的环境下，**管理团队的能力与要素组合至关重要。**

那些能扛过这几年的公司，关键在于转身快，一旦发现要素组合有误就会迅速调整。比如林清轩的创始人在上完全域增长课后，就立即落实了达人分销、身体力行做起了创始人IP；王根祖，原来只做线下，后来线上变成了最大的获客阵地，之前只做TO B，后来TO C也做起来了；原来只做国内业务，现在出海业务也做得风生水起。**合格的创始人，不仅吸收前沿新知很快、做决定很快，落实动作也很快，一旦想明白了就会all in去做。**

## 备注：与《吃法》及王根祖商业体系的关联

本文是李浩（卡思咨询创始人）的年末直播复盘文章，王根祖作为四位嘉宾之一，在"创始人IP"和"出海"两个板块中做了深度分享。核心关联点：

1. **创始人IP → 一条视频获2亿订单**：与《吃法》"短视频驱动的全球营销革命"直接呼应。王老师课堂上即学即用、一条视频拿到一万吨订单的故事，是创始人IP在TO B领域最经典的案例。
2. **智能果昔机 → 全球便利店需求**：文中提到日本711委托富士电机开发类似设备、全球便利店需求激增，与《吃法》"智能果昔机——商用鲜饮加工中心""商业终局——瑞丽模式与1平方米革命"直接对应。
3. **出海策略 → 短视频团队本地化**：王老师提出的"在不同国家建立本地化自媒体团队、精准输出TO B内容"的出海策略，与《吃法》"中国式出海——工具革命下的海外版图与合伙人战略"一脉相承。
4. **海外合伙人模式**：文中提到"招一位业内有人脉、懂行业的资深人士当合伙人"，与《吃法》"合伙人战略"一致。
5. **全域增长框架**：文章核心框架"创始人IP + 出海 + 全域增长"，与《吃法》中"短视频驱动全球营销革命""品牌之盾与AI之翼"形成互补——前者讲方法论，后者讲技术底座和终局图景。
