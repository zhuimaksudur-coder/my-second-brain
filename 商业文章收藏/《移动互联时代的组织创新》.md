# 移动互联时代的组织创新

## 组织创新的重要性

今天组织创新的社会大背景：
- 劳动力成本上升
- 劳动法不公平
- 激励人性

**理论书籍参考：**
- 《第三次工业革命》
- 《零边际成本社会》
- 《人人时代》

**具体案例：**
- 宗毅（芬尼克兹）——裂变式创业组织模式
- 韩都衣舍——小组制柔性供应链
- 腾讯——内部赛马与产品进化

## 具体做法

> 创业是在黑暗中根据自己内心的判断，向着自己认为正确的、能够创造独特价值的方向，孤独前行。不能因为别人的掌声赞誉声而沾沾自喜，更不能因为批评指责声而失望怀疑，需要如履薄冰般谨慎，需要冷静地思考，需要独自扛下所有的压力，一颗强大的内心可能是创业者最重要的特质。**迎着风向前，无论成败，无关他人，做自己认为对的，就好！**

## 与王根祖知识体系的关联

1. **"劳动力成本上升"背景下的组织创新** → 智能果昔机正是用"机器替代人工"解决人力成本上升的组织创新方案
2. **宗毅裂变式创业** → 与瑞丽模式"1+N母子店"的商业裂变逻辑相通
3. **"一颗强大的内心是创业者最重要的特质"** → 与《创业时的那点心酸事儿》中2011年绝境自救的经历完全呼应
4. **移动互联网时代的组织变革** → 在AI时代进一步演变为OPC（一人公司）+AI战队的组织形态
