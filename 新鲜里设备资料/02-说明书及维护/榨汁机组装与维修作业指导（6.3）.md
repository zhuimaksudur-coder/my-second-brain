# 榨汁机组装与维修作业指导（版本 6.3）

═══════════════════════════════

> 文档版本：6.3 | 日期：2019-04-23 | 出品：须要科技（深圳）有限公司

## 一、物料清单（BOM）

中框、杯托、遮光圈、亚克力灯圈+上壳、下壳、悬浮磁环、霍尔开关×2、无刷电机、3pin线×2、2pin线、LED灯条带80cm+屏蔽线、电调、铝传动件、PCBA板

## 二、组装工序（十一步）

### （一）安装灯条
1. 剪灯条 80cm，焊接屏蔽线
2. 灯条背胶粘在亚克力台阶内侧，数据线从上壳小孔穿过（灯条方向不要装反）
3. 灯条两端打热熔胶，数据线焊线处打满胶防止进水短路
4. 安装遮光圈，上平头螺丝（3×8mm）

### （二）安装上壳磁铁
1. 上壳内侧四个孔装磁铁 M10×3，插入磁铁先滴快干胶
2. 用悬浮磁环检测：磁环平稳、悬浮 5-7mm、磁铁无漏装/反装
3. 检测合格后用热熔胶涂满加固，防止运输脱落

> 💡 磁铁方向可用悬浮磁环反装在背面定位。

### （三）安装上壳霍尔开关
1. 霍尔开关线剪短，缠绕电工胶带调节粗细
2. 插入上壳圆孔，不要插到底，尾部留 3mm 在圆孔外侧
3. 检测：放入悬浮磁环，万用表测试开关，0-1.5mm 开、4.5-7mm 关
4. 打热熔胶固定

### （四）安装马达
1. 电源线从中框扁孔穿出
2. 电机安装在中框上，背面上螺丝（PB 3×12mm）固定，装好后旋转马达检测平整度

> ⚠️ 电机安装螺丝之前要打螺纹胶。

### （五）安装上壳与后盖
1. 从扁孔导出灯条线和马达线
2. 固定中框和上壳，上平头螺丝（3×10mm），注意不要压到线
3. 安装铝传动件，检测同心度、间隙

### （六）PCBA 焊板
1. 对比样品焊接器件，注意电容、主板 24V 输出端子正负极
2. PCB 板上有三处需要短路跳线
3. 成品检测：无漏器件、无短路、无虚焊
4. 电脑连接 USB 线检测

### （七）接线
1. 霍尔开关线接 3pin 插头；灯圈线接 3pin 插头
2. 电调及马达线接 2pin 插头和主板 24V 输出端子（检测线颜色合格，接线不得接错，接好后缠绝缘胶带）
3. 霍尔开关 3pin 插头接 PCBA；电调 2pin 插头接 PCBA，电调电源线接 PCBA 24V 输出端子（注意正负极）
4. PCBA 上平头螺丝（3×10mm）固定在中框上

### （八）测试
1. 插电，按下悬浮磁环测试马达是否工作
2. 铝传动件正转、无刮碰异响、无抖动
3. 灯圈正常（详见《检测报告》）

### （九）安装后壳
后盖插入中框，上平头螺丝（3×10mm）固定；注意电源口与 USB 口对位，不要挤压数据线。

### （十）接电源
- 输入 220V 交流电：L——红色、N——蓝色、地线——黄色
- 输出 24V 直流电：白色——正极、黑色——负极
- 三插线、2.5DC 线接对应接线柱，螺丝上紧，打热熔胶做绝缘处理

### （十一）现场安装
1. 电源卡入底壳卡扣，打热熔胶加固
2. 电源三插线从底座后侧孔穿入接到电源适配器接线柱，DC 电源插头插入榨汁机
3. 榨汁机装入底座，上螺丝（PB 5×30mm）固定
4. 装悬浮磁环和杯托

## 三、成品验收标准

- 组装完成后做全检，合格品入成品库
- 发货前做全检，合格后填写《保修卡》及《合格证》，装箱并核对物料发货
- 检测标准详见《6.3圈机品质标准》

## 四、维修作业指导

### 保修判断（填写维修单）
1. 登记设备编码，外观检查拍照，记录是否有进水、跌落痕迹
2. 接通电源，榨汁测试
3. USB 线接电脑，读取榨汁次数，拍照记录
4. 烧新程序再测试

### 故障分类维修表

| 故障现象 | 维修处理 |
|------|------|
| 频繁烧杯、断轴 | 拆下壳检查 PCBA 板（拍照，看是否烧焦、断线）；拆上壳重新组装电机和铝传动件 |
| 铝传动件偏心、过高或过低 | 卡尺寸，更换铝传动件或增加垫片；拆上壳重新组装电机、铝传动件，或更换马达 |
| 榨汁中马达停转 + 滴响 + 灯白光 | 更换电源适配器测试；拆下壳检查 PCBA 板是否烧焦、断线 |
| 马达不反应 + 灯白光 | 强磁铁吸附指定位置检测，拆上壳调整霍尔开关 |
| 马达不反应 + 滴滴响 | 检查磁铁是否脱落；拆下壳检查电路板是否进水、烧焦，更换主板 |
| 马达无故旋转 | 拆上壳调整霍尔开关 |
| 灯不亮 + 其他正常 | 拆灯圈、下壳，单独接灯线测试，更换屏蔽线 |

> 故障自检及保修判定详见《6.3圈机故障自检及保修单》
