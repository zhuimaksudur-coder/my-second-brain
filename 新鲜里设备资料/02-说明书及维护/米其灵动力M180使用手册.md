# 米其灵动力 M180 使用手册

═══════════════════════════════

## 一、产品简介

米其灵动力是一套高效出品饮品的整体解决方案，具有**动态导购、榨汁搅拌、混合加汁、冷藏陈列**等功能。结合独有的封闭式榨汁杯，在有限空间增加更多收益、快速出品、提升经营效率。可制作果汁、果茶、冰激凌、鸡尾酒、奶茶等多种品类。

**主要结构**：点餐牌（可更换 LOGO 面板）、榨汁机、回转链盘、加汁机、出品台、储物柜、脚轮、玻璃冷藏柜

**装箱清单**：米其灵机柜（含玻璃冷藏柜、回转链盘、电控箱）、榨汁机 2 台、加汁机 2 台、彩虹装饰件、产品使用手册、保修卡

> 输入电压默认交流 220V，其他用电规格需提前与指定经销商联系。

## 二、安装指导

### 1. 安装出品台设备底座
1. 摆放加汁机圆柱和榨汁机圆柱，将电线和水管从圆柱底孔引出
2. 安装彩虹管（彩虹管里要提前填充装饰水果）
3. 对齐圆柱与台面螺丝孔，拧螺丝固定
4. 彩虹管固定：45° 对插加汁机圆柱方形凸起，旋转卡紧

### 2. 线路布局
- **左侧电路区**：电源线从桌面出线口插入，从左立柱导入机柜内部，连接电源适配器和电箱
- **右侧水路区**：水管从桌面出线口插入，从右立柱导入机柜内部，尾端插入机柜内的汁底容器
- 吧台线口如无电源线/水管，检查机柜内出线区，抽出存留的线/管重新导入

> ⚠️ 总电箱包含高电压，须由专业人员维护检修！

### 3. 安装榨汁机
1. 插接电源线
2. 榨汁机头插入榨汁机圆柱，上螺丝固定
3. 安装悬浮磁环和杯托（注意磁环方向）

> 使用官方电源适配器：输入 AC170-250V / 输出 DC24V / 400W / 内置过载保护。
> 使用官方榨汁杯：容量 420ml、尺寸 164.7×90.7mm、材料 PP、硅胶，否则设备损坏不予保修。

### 4. 安装加汁机
1. 接插水管、接插电源线
2. 加汁机头插入加汁机圆柱
3. 水管尾部可连接多种底料容器：
   - **冷藏冰箱**（高度＜53cm）：软管从冰箱门封条穿过插入汁底桶
   - **水桶**：插入水桶底部或接保温水桶出水龙头
   - **无菌袋 BIB**

## 三、操作指导

### 控制面板认识

| 面板 | 功能 |
|------|------|
| 总电箱 | 总开关 + 4个AC插座（接榨汁机、加汁机、冷藏柜），内置漏电保护、过载保护 |
| 机柜控制面板 | 回转链盘调速按钮和开关、面板灯光开关、备用AC插座 |
| 冷藏柜控制面板 | 除雾开关（左）、照明开关（中）、制冷开关（右）、温度调节面板（出厂默认设置） |

### 加汁操作
手持带盖果杯对准水嘴向上戳 → 感应磁环被触发后自动加汁 → 水位达到要求后拔下果杯。

### 榨汁操作
将果杯放入榨汁机杯托，垂直向下压住杯盖部分 → 自动识别开始榨汁，不要放手 → 20 秒后自动停止（灯光变白灯）→ 取出果杯。

**榨汁注意事项**：
- 禁止空杯榨汁、禁止不带盖榨汁
- 垂直压杯不可倾斜，不可抖动（否则易导致杯子破损）
- 不得直接握持杯身（会导致杯盖脱落）
- 建议间歇性工作，不可连续运转

## 四、维护指导

**每日清洁三步骤**：
1. **清洁加汁机**：表面、水管及周围桌面；每天使用后清洗管路（持续抽取温水清洗 + 拆下软管水嘴用梳打水浸泡清洗）；每三个月更换管路耗材；发现异味或异物及时清洁；清洁用具必须独立
2. **清洁榨汁机**：表面及积水槽
3. **清洁高频使用区域**：冷藏柜、回转链盘、底料柜等

**加汁机更换水管**：
- 拆装出水嘴：拔下加汁机头，从侧边扣开半圆保护盖，沿缺口方向滑出出水嘴
- 拆装水管：提拉蠕动泵锁钮，打开夹子，取出水管

## 五、故障排查表

### 榨汁机故障

| 故障 | 排查 |
|------|------|
| 无法启动 | 灯不亮→检查接电更换电源；嘀嘀响马达不转→过载保护断电重启；灯亮马达不转→检查/更换感应垫片 |
| 榨汁过程停转 | 过载保护→更换果杯断电重启；温度过高→断电静置半小时 |
| 果杯烧焦、断轴 | 传动件偏心错位→断电检查松动；杯托松动→更换匹配杯托；店员误操作→压杯平稳不倾斜；果杯不良→检查杯底梅花件，换杯试试 |
| 灯圈不亮、异常 | 进水短路导致 |
| 新机榨汁效果差 | 检查电源适配器匹配；铝转动件旋转方向为顺时针 |
| 马达无故空转 | 检查悬浮磁环是否装反，或更换悬浮磁环 |

### 加汁机故障

| 故障 | 排查 |
|------|------|
| 水嘴少量滴漏 | 残留果汁流出及时清洁；水嘴有异物清洗或更换 |
| 不出果汁（水泵工作） | 汁底用完；果汁管插到容器底部；管路漏汁堵塞 |
| 不出果汁（水泵不工作） | 检查感应磁环 |
| 水泵不工作且报警音 | 主控板进水短路 |

### 回转链盘故障

| 故障 | 排查 |
|------|------|
| 不转 | 检查总电闸、调节旋钮和链盘开关；检查是否卡住异物 |
| 旋转过程抖动 | 检查四个角的链盘是否抖动明显，是否卡住异物 |

### 冷藏柜故障

| 故障 | 排查 |
|------|------|
| 不制冷或制冷效果差 | 检查总电源开关、制冷开关；冷凝器结冰→静置24小时再开机；冰箱门未关紧；制冷机组过热保护→散热口不得堵住，静置24小时 |
| 漏水（排水管出水） | 户外温差变化导致（大部分冷凝水由蒸发器挥发）；打开玻璃托板检查内部积水及时清理 |
| 玻璃起雾 | 打开除雾开关，及时清洁表面水渍 |

> ⚠️ 米其灵移动和搬运后，静置 12 小时后再开冷藏柜；冷藏柜不得太阳直射，环境温度不可高于 40℃。
