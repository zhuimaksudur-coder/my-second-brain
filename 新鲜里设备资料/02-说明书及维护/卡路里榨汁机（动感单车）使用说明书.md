## 二、安装说明（四步法）

1. 准备好榨汁机头与单车，连接预留的两根电线
2. 把机头装在单车把手上方，拧螺丝固定（注意机头朝向，不要装反）
3. 连接电源适配器——适配器应安装在隐蔽处防儿童触碰、留通风散热空间、远离易燃物、朝上固定在墙面
4. 装入感应垫片、杯托（注意感应垫片方向，别装反）

## 三、使用说明（榨汁正确姿势）

- 一只手拉起压杯环，放入果杯，让压杯环压紧果杯
- 骑车 5-10 秒钟，榨汁机开始榨汁，20 秒后自动停止榨汁
- 榨汁过程不要取出果杯、不要停止骑车
- 禁止空杯装入榨汁机
- 间歇 20 秒榨汁，不可连续运转

> ⚠️ 使用官方专用杯子、专用电源。使用非官方配件导致设备损坏不予保修！

## 四、维护说明

- 使用前检查底座是否漏水、传动件是否松动
- 不放果杯骑车，测试机器空转有无异响
- 保持清洁，及时清洁积水槽异物、漏汁
- 榨汁机表面、积水槽每天至少清洁一次
- 设备长期停用应切断电源

> ⚠️ 请勿触摸旋转中的铝转动件，摩擦产生的高温会造成皮肤灼伤！

## 五、故障排查表

| 故障 | 原因 / 排查 |
|------|------|
| 无法启动 | 灯不亮 → 检查接电，更换电源试试 |
| | 报警器嘀嘀响、马达不转 → 过载保护，断电重启 |
| | 灯亮、马达不转 → 检查感应垫片是否安装正确，或更换感应垫片 |
| 榨汁过程停转 | 过载保护 → 更换果杯、断电重启 |
| | 疲劳使用温度过高 → 断电静置半小时 |
| 果杯烧焦、断轴 | 设备故障：传动件偏心、上下错位 → 断电检查传动件是否松动，用空杯压紧应平稳不倾斜 |
| | 压杯环松动 → 更换果杯测试，压紧后应平稳不晃动 |
| | 果杯不良 → 手旋杯底梅花件看是否松动或卡死，更换果杯 |
| 灯圈不亮、异常 | 进水短路；安装底座时线路压断 |
| 新机榨汁效果差 | 检查电源适配器是否匹配；检查铝转动件旋转方向为顺时针 |
| 其他问题 | 联系客服，不得私自拆机维修 |
