## 二、安装说明（四步法）

1. 电源卡接在机头底部，把细电线接到电源输出端
2. 把粗电线从底座线孔引入，接到电源输入端
3. 将机头塞入底座，锁紧螺丝固定
4. 装入感应垫片、杯托（注意感应垫片方向，别装反！）

> ⚠️ 不要接错线路，否则会导致设备无法使用或损坏！

## 三、使用说明（榨汁正确姿势）

- 将果杯放入杯座，压住果杯不要松手
- 榨汁机自动识别开始榨汁，榨汁完成后取出果杯
- 榨汁过程不要松手、禁止空杯榨汁、禁止无盖榨汁
- 手压杯子不倾斜、不抖动
- 间歇 20 秒榨汁，不可连续运转

> ⚠️ 使用官方专用杯子、专用电源（DC24V，400W）。使用非官方配件导致设备损坏不予保修！

## 四、维护说明

- 使用前检查底座是否漏水、铝传动件是否松动
- 取下杯托，手压感应垫片，测试机器空转有无异响
- 保持清洁，及时清洁积水槽里的异物、漏汁
- 榨汁机表面、积水槽每天至少清洁一次
- 长期停用应切断电源

> ⚠️ 请勿触摸旋转中的铝转动件，摩擦产生的高温会造成皮肤灼伤！

## 五、故障排查表

| 故障 | 原因 / 排查 |
|------|------|
| 无法启动 | 灯不亮 → 检查接电，更换电源；嘀嘀响、马达不转 → 过载保护，断电重启；灯亮、马达不转 → 检查/更换感应垫片 |
| 榨汁过程停转 | 过载保护 → 更换果杯、断电重启；温度过高 → 断电静置半小时 |
| 果杯烧焦、断轴 | 传动件偏心、上下错位 → 断电检查传动件松动，空杯压紧应平稳；杯托松动 → 更换匹配果杯的杯托；店员误操作 → 手压果杯平稳不倾斜；果杯不良 → 检查杯底梅花件松动或卡死，更换果杯 |
| 灯圈不亮、异常 | 进水短路；安装底座时线路压断 |
| 新机榨汁效果差 | 检查电源适配器是否匹配；检查铝转动件旋转方向为顺时针 |
| 马达无故空转 | 感应垫片装反，更换感应垫片再试 |
| 其他问题 | 联系客服，不得私自拆机维修 |
