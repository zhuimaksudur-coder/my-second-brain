# 加汁机（CB401）使用说明书

═══════════════════════════════

## 一、技术参数

| 项目 | 参数 |
|------|------|
| 名称 | 加汁机 |
| 型号 / 版本 | CB401 / 401 |
| 尺寸 | 255×165×580 mm |
| 重量 | 2.85 kg |
| 材料 | 塑胶件 |
| 输入 | 直流 24V |
| 额定功率 | 32W |
| 待机功耗 | 约 5W |
| 模式 | 纯果汁模式 |
| 噪音 | ≤55 dB |
| 流量 | 2.1 L/min，加汁时间约 10s（根据汁底浓稠度有差异） |
| 配件 | 电源适配器 / 电源线 / 果汁管 / 说明书 / 保修卡 |
| 使用环境 | 室内，放置于加汁冰柜上 |

## 二、安装说明

1. 软管一头接水嘴，另一头穿过圆柱底座插入台下汁底瓶
2. 提拉蠕动泵锁钮，拉开夹子，将软管卡进蠕动泵内
3. 将电源线穿过圆柱底座，插在机头插座上（指示灯亮起）；盖上机头半圆盖，将机头插入圆柱底座即可使用

> ⚠️ 使用专用电源适配器

## 三、使用说明（加汁操作）

1. 手持带盖果杯对准水嘴向上戳
2. 加汁机的感应磁环被触发后自动加汁
3. 观察水位，达到所要加汁量后拔下果杯

## 四、维护及注意事项

- **每天使用后清洗管路**：① 软管外部接清水，持续加汁清洗管路；② 拆下软管和水嘴用温水浸泡清洗
- **每三个月须更换管路耗材**，使用官方专用耗材
- 发现有异味或管路内有异物，及时清洁
- 随时擦拭机身内部的果汁污渍
- 清洁用具须为独立工具，不得与其他混用

## 五、故障排查表

| 故障 | 原因 / 排查 |
|------|------|
| 水嘴少量滴漏 | 刚使用后残留果汁流出（及时清洁）；水嘴内部有异物（清洗或更换水嘴） |
| 不出果汁（水泵工作） | 汁底用完；果汁管未插到容器底部；管路漏汁、堵塞 |
| 不出果汁（水泵不工作） | 感应磁环安装错误，更换再试 |
| 水泵不工作且有报警音 | 主控板故障 |
| 接电没反应、灯不亮 | 检查电源适配器、电线是否接好 |
| 无人操作时无故出汁 | 感应磁环错误安装或异物卡死，清洗或更换感应磁环 |
| 其他问题 | 联系客服 |
