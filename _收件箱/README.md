# 收件箱（Inbox）——知识库的唯一入口

> 铁律：**任何新内容先进收件箱，不直接进正式目录。** 由 WorkBuddy 入库技能定期消化归档。

## 规则

1. 桌面《吃法》创作、网页剪藏、对话洞察 → 先放到这里
2. 入库技能（每日 21:00 自动运行）会执行四步消化：
   - 归类：按内容移入对应主题目录（王根祖观察 / 学习笔记 / 核心技术 / 产品认证 / 出海与市场 / 家书 / 运营与人事）
   - 规范化：补全 frontmatter（title / category / date / tags / description）
   - 建双链：全文检索旧笔记，插入相关笔记链接
   - 记录：每次处理结果写入 `log.md`
3. 消化完成后本目录应保持为空（除了本说明文件）
