本手册是为技术人员对机器进行安全地运输、安装、设置、维护和维修的指导文件。机器的使用和日常清洁工作指引，请参考独立的章节。

### 1.2 重要的安全警告

1. 使用前请仔细阅读本手册；
2. 参照名牌使用正确的电压，并确保电源插座接地良好；
3. 不要在靠近热源或气源的地方储存或使用机器；
4. 设备在清洁或保养前必须断开电源；
5. 防止机器被溅水；
6. 拔插头的时候不要拖拽电缆；
7. 不要把机器和线缆放入水中；
8. 如果水硬度大于8DH，请使用过滤器；
9. 机器安装布置时候，不要倾斜；安装过程中请不要让儿童进入安装现场；
10. 如果线缆损坏，请尽快联系泰州普门电子有限公司购买新的配件更换；
11. 保护机器免受天气影响（如水、热等）；
12. 严禁在户外使用本机器；
13. 维修、清洗和修复工作要由专业的服务人员完成；
14. 为您了的自身安全以及机器的使用寿命，请使用原厂配件；
15. **等电位标注**：如有其他用电设备，需进行等电位连接的，应用标称横截面积为2.5平方~10平方内适当的铜芯导线将本机等电位端与其他设备的等电位端可靠连接。

### 2.3 机器视图

#### 2.3.1 使用操作

**1、整机说明**

机器有喷涂款和不锈钢款两种外观，分别展示正面、侧面、顶面、背面视图。

热水箱可放置于桌面上，也可以隐藏到吧台桌面下方的抽屉中。

**2、开机操作**

*操作步骤一：安装纯净水水桶和废水收集桶*
（附件包含有净水取水管和废水排水管）

*操作步骤二：管路补水操作*
接通电源系统首先执行自检初始化动作，操作屏显示界面。

系统完成自检初始化后，自动进入待机界面。

**3、冰杯加工**

用户挑选冰杯并支付购买后，即可使用智能果茶机来加工制作冰杯，具体步骤如下：

*操作步骤一：冰杯扫码识别*
待机界面，将冰杯封膜上的二维码对准扫码器，机器正确识别后即自动弹开前操作门，操作屏提示撕膜后放置冰杯。

*操作步骤二：冰杯撕膜并放入杯托中*
撕掉冰杯封膜并将冰杯放入加工杯托中，机器提示关门。关上门后，提示开始制作。

*操作步骤三：等待冰杯制作*
冰杯制作过程中操作屏先后提示加工过程信息，请耐心等候。

*操作步骤四：取走冰杯*
冰杯制作完成后，系统自动开门，并持续等待顾客取走冰杯。

系统检测到关门后，即启动执行自动清洗动作。自动清洗完成后系统将返回待机界面，至此冰杯加工过程完成。

#### 2.3.2 维护操作

智能果茶机需要做到每日清洁，以防细菌滋生，维护操作需首先进入维护模式。

*操作步骤一：进入维护界面*
机器正常上电后，在待机界面连续点3次显示屏右侧机器编号位置，系统即进入维护模式界面（含「售卖」和「运维」两个入口）。

*操作步骤二：杀菌清洗*
杀菌清洗主要使用热水，长时间清洗与食品接触部分部件，达到杀菌消毒目的。点击维护界面中的清洗，系统即自动执行刀头、刀杆、清洗筒、硅胶套等杀菌清洗流程。

*操作步骤三：内部清洁*
点击维护界面中的开门，下电机测试，系统即自动将平台移动到靠后位置，待平台停止移动，请即断开电源以确保拆洗清洗筒头、换刀头等操作时的安全。

此时可以进行内部清洁、内部部件表面擦拭、刀头的清洗、清洗筒拆解清洗、废水盘清洁等操作。清洁全部完成之后清洗筒安装归位，安装务必平整，开机，进入待机状态。

*操作步骤五：退出维护界面*
维护结束后，点击维护界面左上角返回箭头，系统即返回待机状态。

运维主要工具：
- 10mm开口扳手2个
- 一次性手套
- 无菌擦拭布等

## 3. 运输与仓储

机器用塑料袋、泡棉、纸板或者木箱包装，以防止损坏、潮湿和灰尘。

任何索赔要求，收货时必须立即检查货物的损坏或损失，不良照片应及时反应给物流公司。

> **⚠️ 当心 — 为避免损坏：**
> - 将机器立式运输；
> - 不要堆叠机器；
> - 使用时机器顶部不要放置液体；
> - 不要在机器顶部放置任何大于5公斤的物体；
> - 装机过程中避免机器倾倒、跌落；
> - 移动机器时，需要排空机器水箱里的水。

## 4. 首次使用

1. 机器放置到运营地点，拆开机器包装，移出机器；
2. 通电后在屏幕左上角（"时间"下面一点的区域），连续点击三下，跳出后台界面，点击"开门"；
3. 检查机器内部：检查机器内部是否有结构损坏；
4. 安装天线，自动连接4G或者WIFI；
5. 安装废水管：拿出废水盒，连接排水管，用卡箍固定，排水管另一头导入废水箱；
6. 给机器连接进水，接入管线机或者纯净水桶；
7. 连接好进水水源，并开机后，机器将自动充填水路系统，待指示灯完全变绿，即可开始正常工作；
8. 第一杯需店员打出，导出气路中的空气。

> **备注：**
> 该机器不适用于户外安装，或放置于强光环境中；不能安装在喷气或喷水的环境中；需要安装在温度5℃到35℃之间的干燥室内。

- 电源插座必须接地；
- 电源开关需放在方便断电处，便于异常时及时断电；
- 机器电源插头规格是10A，插座必须配10A的插座。

将机器电源线的公头一端插入电源的插座中；机器通电后将自动启动，启动需要时间＜1分钟。

## 5. 清洁与维护

### 5.1 清洗和清洁的安全规定

在清洗和清洁之前，请注意以下安全说明！

> **🔴 危险！电击危险！**
> 在任何维修与清洁之前，先关闭机器，然后拔下插头，方可进行维修与清洁！电源已损坏时，不要尝试自行修复，请交给专业技术服务人员处理。

> **⚠️ 当心！机器损坏及人身伤害危险！**
> 机器内刀片很锋利，在清洗期间需要小心。不要在设备内部结构移动的情况下清洗机器。

### 5.2 基本清洁工作

> **备注：** 清洁工作需要根据机器的实际使用状况安排，如果没有特殊情况，请严格按照清洁指引执行操作。

### 5.3 清洁指引

**清洁注意事项：**
1. 擦拭机器时，抹布浸湿后拧干水后才能擦拭机器；
2. 清洁底座内部结构时，用抹布擦拭直到干净；
3. 自动清洗过程中，切勿强行拿出排水管、废水桶等可以直接拆卸的部件；
4. 废水桶、接水盘清洗后需擦干才能装回机器；
5. 冷热水桶需每年进行一次除水垢，或按使用情况操作。

## 6. 常见问题清单

### 问题一：网络不好

| 问题 | 导致结果 | 解决方案 |
|------|---------|---------|
| 网络不好 | 1. 开机时网络不好，APP无法正常开启，长时间连不上，屏幕上会显示网络不好 | 1. 有WIFI尽量连接WIFI |
| | 2. 扫码时出现网络问题，会提示二维码校验失败 | 2. 移动机器摆放位置至信号更强的地方 |
| | 3. 制作中出现网络问题，制作视频会偶尔黑屏或不显示 | 3. 配置信号更强的4G天线 |
| | | 4. 4G连接问题有可能是运营商未能覆盖当前区域，请尝试更换其他运营商 |
| | | 5. 扫码时出现短暂性网络卡顿，可以退出APP或者重启机器进行重新连接网络 |

### 问题二：产品复冻

| 问题 | 导致结果 | 解决方案 |
|------|---------|---------|
| 产品复冻 | 1. 搅拌刀头卡顿，无法正常搅拌 | 1. 轻微复冻的产品，可以在进机器制作前用手捏压，或者轻敲果杯至杯内果冰分开 |
| | 2. 完成制作后有大块冰块未能被搅碎 | 2. 严重复冻的产品，不能直接进机器制作。如果已经制作，并发现制作过程中无法正常搅拌，应立刻点击屏幕上的"紧急停止"，设备将立即停止制作。按"开门"将冰杯取出后，按"复位"并关门 |

### 问题三：机器漏水

| 问题 | 导致结果 | 解决方案 |
|------|---------|---------|
| 机器漏水 | 每次清洗完废水废水无法排出，从分水盘溢出至机箱，机箱漏水 | 保持排水管布管流畅，拐弯处接直角弯头，以免水管憋住或者水管拐弯处水位高于排水口 |
| | 水箱排水扣处滴漏 | 需要拧紧螺母，并检查堵头是否丢失 |

### 问题四：机器不能启动完成

| 问题 | 导致结果 | 解决方案 |
|------|---------|---------|
| 机器不能启动完成 | 开机后APP无法启动完成，一直显示"设备开机自检中，请稍等"，"串口检测失败"等提示 | 拆掉门板螺丝，取下门板，检查门板内的线组是否松动 |

### 问题五：开机白屏

| 问题 | 导致结果 | 解决方案 |
|------|---------|---------|
| 开机白屏 | 开机后APP无法自动启动，显示白屏APP文件损坏 | 屏幕右上角轻点三下，点击"卸载APP"并回到屏幕桌面，点击打开浏览器，重新扫码下载并安装 |

## 7. 注意事项

1. 使用过程中，请不要随意拆卸产品外壳，以免造成损坏、发生触电和其它安全事故；
2. 使用过程中，请勿用尖锐物品接触产品，以免损伤外壳；
3. 使用过程中，请勿将手或其它物体伸入机器内部；
4. 产品使用避免放置在潮湿、高温或有明火的环境，以免引发火灾或电器故障；
5. 若长时间不使用，请关闭电源拔掉电源线，并放置在干燥通风环境；
6. 使用过程中发现任何异常，如异味、异响等，请立即停止使用并与售后服务联系；
7. 请及时做好运维保养工作，防止细菌滋生、菌落总数超标；
8. 请定期清洁产品外观，保持干净整洁，清洁时使用柔布擦拭避免刮伤表面；
9. 若产品需要维修，请务必联系售后服务处理，切勿自行拆卸或修理；
10. **若冰杯有明显融化迹象，请勿售卖给消费者。**
